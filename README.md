# 펫허브연구소 레시피북

MMA 허벌리스트 스터디에서 개발한 반려견 허브 레시피를 모아두고, **반려견 체중과 급여 일수에 맞춰 재료 용량을 자동 계산**해주는 앱입니다.

## 주요 기능

- 레시피 11종 수록 (내복 9 / 외용 2)
- **배치 계산기** — 제품 성격에 따라 두 가지 방식으로 계산
  - *개체 맞춤 제작형* (파우더·페이스트): 체중 × 급여일수 → 이번에 만들 총량과 재료별 무게
  - *표준 배치 제작형* (시럽·디콕션·오일): 만들 총량을 정하면 → 재료별 무게 + 그 체중의 1회 급여량 + 며칠치인지
- 레시피 추가 · 수정 · 삭제 (기기 내 저장)
- 완성량 **실측 / 추정치** 구분 표시 — 인퓨즈드 오일·팅쳐처럼 허브가 용매를 흡수해 실제 회수량이 줄어드는 제형은 경고를 띄웁니다

## 기술 스택

Expo SDK 57 · React Native · expo-router · NativeWind · zustand + AsyncStorage · TypeScript

## 개발

```bash
npm install
npm run web        # 웹 개발 서버
npm start          # Expo Go (모바일)
npm run typecheck  # 타입 체크
npm run build:web  # 정적 빌드 (dist/)
```

환경변수가 필요하면 `.env.example`을 복사해 `.env.local`을 만드세요.

## 배포

`main` 브랜치에 푸시하면 GitHub Actions가 정적 빌드 후 GitHub Pages로 자동 배포합니다
(`.github/workflows/deploy.yml`).

## 주의

이 앱은 허벌리스트의 제품 설계를 돕는 **계산 도구**이며, 수의학적 진단이나 처방을 대체하지 않습니다.
수록된 용량은 스터디 자료에 근거한 값으로, 실제 급여 전 전문가 확인이 필요합니다.
